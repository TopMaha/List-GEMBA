# GEMBA Center — TENNECO Chonburi

ศูนย์รวมลิงก์งาน GEMBA ทั้ง 3 รายการของโรงงาน TENNECO ชลบุรี
เปิดใช้งานได้ทันทีจากมือถือ แท็บเล็ต หรือคอมพิวเตอร์หน้างาน

| รายการ | ขอบเขต |
|---|---|
| **GEMBA QC** | ตรวจติดตามคุณภาพหน้างาน จุดเสี่ยงของเสีย และการควบคุมกระบวนการผลิต |
| **GEMBA SAFETY** | ตรวจความปลอดภัยพื้นที่ปฏิบัติงาน สภาพไม่ปลอดภัย และการใช้ PPE |
| **GEMBA LSW&5S** | Leader Standard Work และการตรวจ 5S ความเป็นระเบียบของพื้นที่ทำงาน |

## การใช้งาน

เปิดไฟล์ `index.html` ได้เลย — ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์

1. กด **จัดการลิงก์** แล้ววางลิงก์ของแต่ละรายการ (Google Form, Microsoft Forms, SharePoint, Power Apps ฯลฯ)
2. กด **บันทึก** — การ์ดจะเปลี่ยนเป็นสถานะ "พร้อมใช้งาน" ทันที
3. ส่งลิงก์หน้านี้ให้ทีม หรือกด **พิมพ์** เพื่อติดบอร์ดหน้างาน

## การเก็บข้อมูลลิงก์

มี 2 แบบ เลือกได้ตามการใช้งาน

**แบบที่ 1 — กรอกผ่านหน้าเว็บ** ลิงก์เก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ๆ
เหมาะกับเครื่องประจำจุด ถ้าต้องตั้งค่าหลายเครื่อง ใช้ปุ่ม **สำรอง / กู้คืน** คัดลอก JSON ไปวางที่เครื่องอื่นได้

**แบบที่ 2 — ฝังถาวรในไฟล์ (แนะนำสำหรับใช้ร่วมกันทั้งทีม)**
แก้ค่า `url` ในส่วน `ITEMS` ที่ต้นแท็ก `<script>` ของ `index.html` แล้วทุกคนที่เปิดจะเห็นลิงก์ครบทันทีโดยไม่ต้องตั้งค่าเอง

```js
var ITEMS = [
  {
    id: 'qc', cat: 'Quality', title: 'GEMBA QC',
    desc: '...',
    url: 'https://forms.office.com/r/xxxxxxxx',   // <-- ใส่ลิงก์ตรงนี้
    ...
  },
  ...
];
```

## เผยแพร่ให้ทีมผ่าน GitHub Pages

Settings → Pages → Source เลือก **Deploy from a branch** → Branch `main` / โฟลเดอร์ `/ (root)` → Save
รอสักครู่จะได้ URL สำหรับแชร์ให้ทีมเปิดจากมือถือได้ทันที

## รายละเอียดทางเทคนิค

- HTML/CSS/JS ล้วน ไฟล์เดียว ไม่มี dependency และไม่มี build step
- ธีมน้ำเงิน–ขาว, ฟอนต์ IBM Plex Sans Thai (โหลดจาก Google Fonts พร้อม fallback สำหรับใช้งานออฟไลน์)
- Responsive ทดสอบที่ 320 / 375 / 768 / 1280 px
- ผ่าน WCAG AA (contrast ≥ 4.5:1), touch target ≥ 44px, รองรับคีย์บอร์ด, screen reader และ `prefers-reduced-motion`
- รับเฉพาะลิงก์ `http` / `https` เท่านั้น และ escape ข้อมูลก่อน render ทุกจุด
