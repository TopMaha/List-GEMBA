# GEMBA Center — TENNECO Chonburi

ศูนย์รวมลิงก์งาน GEMBA ทั้ง 3 รายการของโรงงาน TENNECO ชลบุรี
เปิดใช้งานได้ทันทีจากมือถือ แท็บเล็ต หรือคอมพิวเตอร์หน้างาน

| รายการ | ขอบเขต |
|---|---|
| **GEMBA QC** | ตรวจติดตามคุณภาพหน้างาน จุดเสี่ยงของเสีย และการควบคุมกระบวนการผลิต |
| **GEMBA SAFETY** | ตรวจความปลอดภัยพื้นที่ปฏิบัติงาน สภาพไม่ปลอดภัย และการใช้ PPE |
| **GEMBA LSW&5S** | Leader Standard Work และการตรวจ 5S ความเป็นระเบียบของพื้นที่ทำงาน |

## ภาพรวม Audit (`dashboard.html`)

แดชบอร์ดรวมทั้ง 3 ระบบในหน้าเดียว ออกแบบให้เปิดบนมือถือระหว่างเดิน Gemba
สลับไปมากับหน้าลิงก์ได้จากแถบ **ลิงก์ GEMBA / ภาพรวม Audit** ด้านบน

- **ตัวเลขสรุป** — งานค้างทั้งหมด · เลยกำหนด · รุนแรงสูง · เดินตรวจสัปดาห์นี้ (พร้อม % ทำตามแผน)
- **สถานะแต่ละระบบ** — งานค้างแยกตามขั้นตอน · QC แยกรายสาย VSM1–4 · Safety แยกตามความรุนแรง
- **ต้องจัดการก่อน** — รวมใบแจ้งที่ยังไม่ปิดของทุกระบบ เรียงจากเลยกำหนด → ความรุนแรง → วันครบกำหนด
  กรองตามระบบและพื้นที่ได้ แตะรายการเพื่อเปิดใบนั้นในแอปโดยตรง

**ข้อมูลมาจากไหน** — หน้านี้ไม่ได้ต่อเซิร์ฟเวอร์เอง แต่อ่านสำเนาข้อมูลที่แอปทั้ง 3 เก็บไว้ใน `localStorage`
ของเบราว์เซอร์เครื่องนั้น ซึ่งอ่านข้ามกันได้เพราะทุกแอปอยู่บนโดเมนเดียวกัน (`topmaha.github.io`)
จึงไม่ต้องใช้โทเคน ไม่ต้องแก้หลังบ้าน และใช้ได้แม้ไม่มีสัญญาณ

| ระบบ | คีย์ที่อ่าน | ต้องตรงกับ |
|---|---|---|
| GEMBA QC | `qc.db.v2` · `qc.session` · `qc.admin` | `src/lib/db.ts` · `src/lib/session.ts` ของ QC-Audit- |
| GEMBA SAFETY | `safety.db.v1` · `gemba.session` · `gemba.admin.session` | ของ Gemba-Safety |
| GEMBA LSW&5S | `gemba.db.v3` · `gemba.session` · `gemba.admin.session` | ของ Gemba_Audit |

> ⚠️ ถ้าแอปไหนขึ้นเลขเวอร์ชันคีย์ (เช่น `qc.db.v3`) ต้องแก้ `SOURCES` ใน `dashboard.html` ตามด้วย
> ไม่งั้นการ์ดของระบบนั้นจะขึ้นว่า "ยังไม่มีข้อมูลบนเครื่องนี้"

- ตัวเลขเป็นปัจจุบันเท่ากับครั้งล่าสุดที่เปิดแอปนั้นบนเครื่องนี้ (แอปซิงก์ทุกครั้งที่เปิดและทุก 1 นาที)
  เปิดแอปแล้วกลับมาหน้านี้ ตัวเลขอัปเดตเองทันที
- สิทธิ์ดูภาพรวมใช้ด่านเดียวกับหน้าแดชบอร์ดของแต่ละแอป — บัญชีที่ไม่ได้เปิดสิทธิ์ “แดชบอร์ด” จะไม่เห็นตัวเลขของแอปนั้น
- ต้องเปิดจาก `https://topmaha.github.io/List-GEMBA/dashboard.html` — เปิดจากไฟล์ในเครื่องจะไม่เห็นข้อมูลของแอป
- **QR ประจำพื้นที่** — `dashboard.html?zone=VSM2` เปิดมาพร้อมกรองพื้นที่ VSM2 (ใส่ `&src=qc` / `safety` / `lsw` เพื่อกรองระบบด้วย)

## การใช้งาน

เปิดไฟล์ `index.html` ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์
(ต้องมีโฟลเดอร์ `assets/` ที่เก็บโลโก้ TENNECO อยู่ข้างกันด้วย)

1. กด **จัดการลิงก์** แล้ววางลิงก์ของแต่ละรายการ (Google Form, Microsoft Forms, SharePoint, Power Apps ฯลฯ)
2. กด **บันทึก** — การ์ดจะเปลี่ยนเป็นสถานะ "พร้อมใช้งาน" ทันที
3. ส่งลิงก์หน้านี้ให้ทีม หรือกด **พิมพ์** เพื่อติดบอร์ดหน้างาน

## การเก็บข้อมูลลิงก์

มี 2 แบบ เลือกได้ตามการใช้งาน

**แบบที่ 1 — กรอกผ่านหน้าเว็บ** ลิงก์เก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ๆ
เหมาะกับเครื่องประจำจุด ถ้าต้องตั้งค่าหลายเครื่อง ใช้ปุ่ม **สำรอง / กู้คืน** คัดลอก JSON ไปวางที่เครื่องอื่นได้

**แบบที่ 2 — ฝังถาวรในไฟล์ (แนะนำสำหรับใช้ร่วมกันทั้งทีม)**
แก้ค่า `url` ในส่วน `ITEMS` ที่ต้นแท็ก `<script>` ของ `index.html` แล้วทุกคนที่เปิดจะเห็นลิงก์ครบทันทีโดยไม่ต้องตั้งค่าเอง

```js
var ITEMS = [
  {
    id: 'qc', cat: 'Quality', title: 'GEMBA QC',
    desc: '...',
    url: 'https://forms.office.com/r/xxxxxxxx',   // <-- ใส่ลิงก์ตรงนี้
    ...
  },
  ...
];
```

## เผยแพร่ให้ทีมผ่าน GitHub Pages

Settings → Pages → Source เลือก **Deploy from a branch** → Branch `main` / โฟลเดอร์ `/ (root)` → Save

## รายละเอียดทางเทคนิค

- HTML/CSS/JS ล้วน ไม่มี dependency และไม่มี build step — 2 หน้า: `index.html` (ลิงก์) · `dashboard.html` (ภาพรวม Audit)
- ธีมน้ำเงินกรมท่า–ขาว ใช้สีแบรนด์ `#233D93` จากโลโก้ TENNECO (`assets/tenneco-logo.png` พื้นโปร่งใส ใช้ได้ทั้งบนพื้นขาวและกลับเป็นสีขาวบนพื้นน้ำเงิน)
- ฟอนต์ IBM Plex Sans Thai (โหลดจาก Google Fonts พร้อม fallback สำหรับใช้งานออฟไลน์)
- Responsive 3 รูปแบบ: มือถือ (การ์ดแบบกะทัดรัด, หน้าต่างจัดการลิงก์เป็น bottom sheet) · แท็บเล็ต (การ์ดแนวนอน) · คอมพิวเตอร์ (การ์ด 3 คอลัมน์) — ทดสอบที่ 320 / 375 / 768 / 1366 px
- ผ่าน WCAG AA (contrast ≥ 4.5:1), touch target ≥ 44px, รองรับคีย์บอร์ด, screen reader และ `prefers-reduced-motion`
- รับเฉพาะลิงก์ `http` / `https` เท่านั้น และ escape ข้อมูลก่อน render ทุกจุด
